# DemoScope

CS2 Demo & FACEIT Analytics — публичная стартовая оболочка проекта.

## Запуск локально
Открой `index.html` в браузере.

## Публикация
Этот проект пока является статической демонстрационной страницей. Форма принимает и проверяет формат FACEIT-ника/ссылки, но **не загружает реальные данные**.

Для реальной статистики нужен серверный API-интеграционный слой; секретный FACEIT API key нельзя помещать в браузерный код. Для анализа координат, позиций и событий потребуется отдельный парсер CS2 demo-файлов.

## Деплой
Можно импортировать репозиторий в Vercel или опубликовать статический сайт через другой хостинг. Для автоматических обновлений подключите GitHub-репозиторий.
